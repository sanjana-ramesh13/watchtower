# WatchTower

A website monitoring and security platform.

## About

WatchTower is a full-stack application that monitors website availability and performance.

## Phase 1 Goal

Build a basic web app where users can:
- Sign up and log in
- Add websites to monitor
- See uptime/downtime history
- Receive email alerts

## Technology Stack

- Backend: Python + Flask
- Database: PostgreSQL
- Background Jobs: Celery + Redis
- Frontend: HTML + CSS + JavaScript
